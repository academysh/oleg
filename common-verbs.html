Common verbs

1 · To be — am / is / are

SubjectPositiveNegativeQuestion
Iam (I'm)I'm notAm I …?
he / she / itis (he's)isn'tIs she …?
you / we / theyare (we're)aren'tAre you …?

2 · have, like, want, need, go — Present Simple

I / you / we / theyhe / she / itExample
havehasShe has a brother.
gogoesHe goes to work by bus.
like · want · needlikes · wants · needsShe wants a coffee.
don't / doesn't + base verb: I don't like tea. She doesn't have a car.
Do / Does + subject + base verb: Do you want some tea? Does he go to school?
want / need + noun or want / need + to + verb: I want a bike. I want to go home.

3 · can / can't

PositiveNegativeQuestion
She can swim.She can't swim.Can she swim?
can is the same for every person: I can, he can (no -s). After can we use the base verb without to.

4 · There is / There are

PositiveNegativeQuestion
There is a bank. There are two shops.There isn't a bank. There aren't any shops.Is there a bank? Are there any shops?
